FormulaSnip 公式快贴 1.0.0
Windows 10 / 11，64 位便携版

【快速开始】
1. 完整解压压缩包，双击 FormulaSnip.exe。
2. 点击“设置”，选择识别服务并填入自己的 API Key。
   - 视觉模型：填写接口地址、支持图片输入的模型名称、API Key。
     OpenAI 官方接口默认 https://api.openai.com/v1，默认模型 gpt-5.4-mini。
     其他兼容服务须填写其提供的地址、视觉模型名和相应 Key。
   - Mathpix：填写 Mathpix App ID 和 App Key。
3. 保存设置。按 Ctrl+Alt+M，用鼠标拖动框选一条公式。
4. 松开鼠标后自动识别。按 Esc 或右键取消截图。
5. 核对右侧结果，可直接编辑。默认自动复制 LaTeX。

【粘贴到 Word】
方式一：点击“复制 Word 公式”，在 Word 正文按 Ctrl+V。
        不同版本粘贴兼容性不同；若显示源码或空白，请用方式二。
方式二：点击“导出 Word (.docx)”，保存后用 Word 打开。
        文档内是可继续编辑的原生公式；可复制到你的论文或报告。
方式三：支持 LaTeX 输入的 Word 中，按 Alt+= 插入公式，
        在“公式”选项卡将输入方式切换为 LaTeX，再粘贴源码并转换为专业格式。

【其他操作】
- 支持导入 PNG/JPG/BMP/WebP/TIFF 或粘贴剪贴板图片；随后点击“识别当前图片”。
- Ctrl+Enter 可识别已导入图片。
- “载入示例”不调用接口，可无 Key 体验复制、预览和导出。
- “预览公式”使用默认浏览器离线显示 MathML。
- 快捷键可在设置中修改；若被其他程序占用，请换一个组合。
- 最小化后保留快捷键。关闭窗口即退出，再次使用需重新打开。
- 同一用户会话只允许运行一份工具。

【服务与数据】
- 本软件不附带 API Key 或免费额度，识别服务可能按其规则收费。
- ChatGPT 订阅不等于 OpenAI API 额度。模型和接口权限以服务商账号实际开通情况为准。
- 仅在截图完成自动识别或主动识别时，将所选图片发送到你配置的接口。
- 程序不会将整张桌面发送到接口，只发送选中区域。
- 请仅使用自己信任的接口地址，Key 必须与该服务相匹配。
- 截图和本次会话历史保存在内存；关闭工具即清除，不自动保存截图文件。
- 设置位于 %LOCALAPPDATA%\FormulaSnip\settings.json。
- 勾选保存密钥时，使用 Windows 当前用户 DPAPI 加密；不会将 Key 明文保存。
  将设置文件复制到另一用户或电脑后，通常需要重新输入 Key。
- 预览生成本地临时 HTML，在正常退出时删除；手动导出的 Word 文件由你保留。

【识别与转换边界】
- 请裁紧公式，尽量保持清晰、水平。识别可能有误，尤其是手写、模糊图及复杂排版。
- 常见分式、根式、上下标、求和、矩阵、分段函数和 aligned 多行公式已进行转换检查。
- 特殊宏、完整 LaTeX 文档和部分高级排版不支持 Word 转换；仍可复制原始 LaTeX。
- 已使用本机模拟服务测试请求/响应/错误流程，未使用真实用户 Key 验证识别准确率。
- 已检查生成的 DOCX 结构并成功读取。本环境未安装 Word，实际 Word 粘贴与视觉显示尚未实测。

【常见问题】
认证失败：检查 Key、Mathpix App ID、模型权限和额度。
模型不存在 / 不支持：填写你的服务实际支持图片与 Chat Completions 的模型。
连接失败：检查网络、接口地址和所用服务的地区可用性。
快捷键不工作：先确认工具正在运行；修改快捷键或点击“截图识别”。
Word 只显示文本：改用“导出 Word (.docx)”。

完整图文说明：同目录“使用说明.html”。
源码：源码.zip；依赖许可：第三方许可.txt。
